# trend_usp_v1 — 연관 검색어 기반 시장 트렌드 · USP · 부스 컨셉 진단 (독립 실행 폴더)

한국 수출기업이 제품 스펙(한국어)과 진출 국가를 입력하면,
**현지 소비자가 현지 언어로 검색한 Google 연관 검색어·연관 주제**를 수집해
① 4단계 클러스터링 ② 경쟁 제품 대비 USP 매트릭스 ③ 박람회 부스 컨셉을 **한국어로** 제공합니다.

> 원칙
> - 수집은 현지 소비자의 언어로, 분석·전달은 한국어로 (슬로건·피칭 문구는 바이어 언어 원문 + 한국어)
> - 모든 정보에 근거를 표시: **실측 / 탐색 검증 / 검색 확인 / 사용자 입력 / AI 참고**
> - 숫자는 코드만 만든다. 피칭 월 숫자는 사용자가 입력한 값만 허용
> - 신호가 없는 칸은 억지로 채우지 않고 접는다

## 실행

```bash
pip install -r requirements.txt
cp .env.example .env            # OPENAI_API_KEY 입력 (상위 SABUZAK/.env 공유도 가능)
python app.py                   # http://127.0.0.1:5080  (포트 변경: TREND_USP_PORT=5081 python app.py)
python cli.py --name 약과 --country 미국 --strengths "손에 안 묻는 식감" --certifications HACCP \
    --shelf-life "상온 12개월" --pack-format "개별 포장 30g × 10입"
python cli.py --name 약과 --country 미국 --json   # 전체 JSON
python -m unittest discover -s tests -v          # 오프라인 테스트 (네트워크 불필요)
```

## 입력

| 구분 | 항목 |
|---|---|
| 필수 | 제품명, 진출 국가 |
| 선택 | 제품 강점, 주요 원료, 보유 인증, 가격대 |
| 선택 (바이어 피칭용) | 유통기한, 포장 단위·형태, MOQ·납품가, 타깃 유통채널, 알고 있는 경쟁 제품·가격 |

유통기한·포장·MOQ·유통채널 중 **하나라도 입력해야 바이어 피칭 월**을 만듭니다.

## 파이프라인

| 단계 | 처리 | 주체 |
|---|---|---|
| ⓪ 국가 프로필 | `constants/country_profiles.py` (35개국: ISO 코드, 검색 언어, 바이어 언어, Google 신뢰도). 없는 국가는 LLM 추정 | 코드 |
| ① 시드 | 제품 시드(현지어+영문) 최대 3개 + 카테고리 시드 1~2개 | LLM (light) |
| ② 수집 | 제품+카테고리 시드를 **항상 함께** `related_queries` + `related_topics`. 10개 미만이면 5년 → 글로벌 → (최후) AI 추정 | pytrends |
| ③ 전처리 | 검색어·주제 병합, 급상승 우선, Breakout(+5000%↑) 표시, 최대 30개 | 코드 |
| ④ 분류 | 4개 분류 + 제외(명백히 무관한 것만). 경쟁 브랜드는 경쟁 인식, 브랜드+구매는 구매 단계. 번호로만 참조 → 목록에 없는 검색어 폐기 | LLM (light) + 코드 검증 |
| ④-b 탐색 검증 | 검색어 2개 미만인 분류만 탐색 검색어 제안 → ⑤-통합에서 **검색량이 있는 것만** "탐색 검증"으로 표시 | LLM (light) + pytrends |
| ⑤ 시장 맥락 | 경쟁 제품 후보(브랜드+제품 / 구체적 현지 음식, 카테고리명·한국 제품 금지) + 바이어 체크포인트 | LLM (strategy), AI 참고 |
| ⑤-통합 | 5년 주간 조회 한 단계에서 증감 배지 + 탐색 검증 + 경쟁 제품 검색량 비교. 우리 제품 시드를 모든 묶음에 기준점으로 포함 → "우리 제품 대비 ×N" | pytrends |
| ⑥ 배지 | 전년 동기 대비 증감(최근 13주) → 구글 급상승 % → 없음 | 코드 |
| ⑦ USP | 경쟁 제품 불만 → 우리의 해결(입력 스펙 근거) → 대비가 드러나는 헤드라인. 상투어·핵심어 불일치·미입력 인증 검사 후 걸린 행만 1회 재생성 | LLM (strategy) + 코드 검사 |
| ⑧ 부스 | 슬로건 / 비교 시식 / 피칭 월 / 진열을 구조화 + 근거 참조(검색어·USP 행·입력 항목). 피칭 월 숫자는 입력값에 있는 것만 통과 | LLM (strategy) + 코드 검사 |

- 모델: light = `TREND_USP_MODEL`(기본 gpt-4o-mini), strategy = `TREND_USP_STRATEGY_MODEL`(기본 gpt-4o)
- 중국·러시아처럼 Google 점유율이 낮은 국가는 결과 상단에 신뢰도 경고가 고정됩니다.
- pytrends 응답은 `.cache/`에 24시간 캐시됩니다. 화면의 "캐시 무시" 또는 `--force`로 새로 조회.
- 오래된 brotli(<1.2.0)가 설치된 PC에서도 동작하도록 br 압축 요청을 끕니다 (`http_compat.py`).

## 알려진 한계

- **실제 Google Trends / OpenAI 응답으로는 개발 환경에서 검증하지 못했습니다** (네트워크 차단).
  가짜 응답(`tests/test_offline.py`)으로만 검증했으니 처음 실행 시 `python cli.py ... --debug`로 로그를 확인해 주세요.
- 분석 1회에 Google 요청 약 8~12회, OpenAI 호출 약 6~7회(재생성 포함)가 발생합니다. 429(요청 과다)가 잦으면 잠시 후 다시 시도하세요.
- 경쟁 제품 가격은 AI 학습 시점 기준 추정입니다("AI 참고"). "검색 확인"은 현지에서 검색된다는 뜻이지 매대 입점 증명은 아닙니다.
- Google 트렌드 수치는 절대 검색량이 아니라 0~100 상대 지수입니다.
