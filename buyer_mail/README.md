# 사부작 팔로업 메일 프로토타입

회사 공용 팔로업 이메일 템플릿을 하나 만들어두면, 바이어 목록에서 체크박스로 고른 바이어들에게
박람회명·이름·회사명만 자동 치환해서 담당자 본인 Gmail로 대량 발송하는 기능만 떼어낸 최소 테스트 앱입니다.

## 1. 준비물 (최초 1회, 개발자가 설정)

### Google OAuth 클라이언트 발급
1. [Google Cloud Console](https://console.cloud.google.com/) 에서 새 프로젝트 생성
2. "API 및 서비스 > OAuth 동의 화면" 에서 외부(External) 선택 후 앱 이름 등 기본 정보 입력
   - 테스트 단계에서는 "테스트 사용자"에 실제 로그인할 직원 Gmail 주소를 추가해야 로그인 가능
3. "사용자 인증 정보 > OAuth 클라이언트 ID 만들기" → 애플리케이션 유형: 웹 애플리케이션
   - 승인된 리디렉션 URI: `http://localhost:5000/auth/google/callback`
4. 발급된 클라이언트 ID / 클라이언트 보안 비밀을 `.env`에 입력

### 토큰 암호화 키 생성
```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```
출력값을 `.env`의 `TOKEN_ENCRYPT_KEY`에 넣습니다.

### OpenAI API 키
`OPENAI_API_KEY`에 발급받은 키를 입력합니다.

## 2. 설치 및 실행

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

`.env` 파일을 열어 위에서 준비한 값들을 채운 뒤:

```bash
python run.py
```

브라우저에서 `http://localhost:5000` 접속 → "Google로 로그인" 클릭.

## 3. 사용 흐름

1. Google 로그인 (앱 로그인 + Gmail 발송 권한을 한 번에 승인) → 바로 바이어 목록(메인 화면)으로 이동
2. 상단 "내 정보"에서 이름·회사·직급 입력 (메일 서명에 자동으로 들어감)
3. 상단 "메일 템플릿"에서 버전 1~3 중 하나를 골라 수정 방향(예: "더 짧고 캐주얼하게")을 입력하고
   "템플릿 내용 수정" 클릭 → 제목/본문 확인 후 "템플릿 저장" → 마음에 들면 "이 버전을 발송용으로 사용" 클릭
   - `{{exhibition}}`, `{{name}}`, `{{company}}`, `{{date}}`, `{{sender_name}}`, `{{sender_company}}`,
     `{{sender_position}}` 를 넣으면 발송 시 자동 치환됩니다
   - 박람회 구분 없이 회사 전체가 공용으로 쓰는 템플릿이며, 3개 버전 중 "발송용"으로 지정된 것만 실제 사용됩니다
4. 바이어 목록에서 "+ 바이어 등록" → 박람회 선택(드롭다운) + 이름 + 회사 + 이메일만 입력
   - 박람회 목록은 지금은 더미 데이터 5개가 미리 채워져 있습니다 (`app/__init__.py`의 `DUMMY_EXHIBITIONS`).
     나중에 사부작 본 프로젝트의 실제 박람회 데이터로 교체하면 됩니다
   - 등록 화면에서 "명함 스캔해서 채우기"로 명함 사진을 올리면 이름·회사·이메일이 자동으로 채워지고,
     전화번호 등 나머지 정보는 특이사항으로 자동 등록됩니다 (내용은 저장 전에 다시 확인/수정 가능)
   - 등록 후에는 바이어 목록의 "특이사항" 칸에서 바로 메모를 수정할 수 있고, 칸 밖을 클릭하면 자동 저장됩니다
5. 바이어 목록에서 체크박스로 원하는 바이어를 고르고 "선택 발송" (상단 "전체 선택" 버튼으로 한 번에 전체 선택 가능)
   → 확인 후 발송용 템플릿 그대로 일괄 발송
   - 개별 바이어만 내용을 살짝 바꿔 보내고 싶으면 "팔로업"에서 "템플릿으로 채우기" → 수정 → 개별 "발송하기"도 가능
6. 발송된 지 21일이 지난 바이어는 목록 맨 위, 연분홍색 배경으로 자동으로 올라옵니다 (재발송 대상 표시)
7. 박람회별로 걸러 보고 싶으면 목록 상단 드롭다운으로 필터링 가능

## 4. 참고

- `127.0.0.1:5000`으로 접속하든 `localhost:5000`으로 접속하든, 앱이 자동으로 `.env`의
  `GOOGLE_REDIRECT_URI`에 맞는 주소로 리디렉션합니다 (두 주소는 브라우저 쿠키가 서로 달라서
  섞어 쓰면 로그인이 한 번씩 실패하는 문제가 있었음).
- `gmail.send` 스코프만 요청하므로 이 앱은 사용자의 메일함을 읽거나 삭제할 수 없습니다.
- refresh_token은 평문으로 저장되지 않고 `TOKEN_ENCRYPT_KEY`로 암호화되어 SQLite(`instance/sabuzaktest.db`)에 저장됩니다.
- "선택 발송"은 되돌릴 수 없는 대량 발송이므로, 먼저 본인 이메일로 개별 발송해서 템플릿을 검토한 뒤
  실제 바이어들에게 발송하는 것을 권장합니다.
- 이 폴더는 사부작 본 프로젝트와 분리된 격리 테스트용입니다. 검증 후 본 프로젝트에 통합할 때는
  더미 `Exhibition` 데이터를 본 프로젝트의 실제 박람회 데이터로 교체하고, 기존 로그인 시스템과의
  통합 방식을 다시 검토해야 합니다.
