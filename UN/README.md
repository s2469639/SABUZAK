# un_comtrade_market_research — UN Comtrade 무역통계 시장조사 (독립 실행 폴더)

HS코드(6자리) + 국가를 입력하면 UN 공식 무역통계(UN Comtrade)로 ①글로벌
수입 순위 ②한국의 경쟁력(점유율) ③3개년 성장 트렌드(CAGR)를 조사하고,
OpenAI가 그 수치를 근거로 전략적 시사점을 한국어로 작성합니다.

**여러 후보국을 한 번에 비교하고 싶다면** `/matrix` 화면(또는
`cli.py --matrix`)을 쓰세요. KOTRA TriBig, ITC Export Potential Map 같은
전문 무역조사기관들이 실제로 쓰는 방식과 같은 구조로, 후보국들을 "그 나라
수입시장 성장률 x 한국 점유율" 2축 매트릭스 위에 한 번에 올려서 비교합니다
(아래 "매트릭스 비교" 절 참고).

`tavily_market_research`(뉴스 트렌드), `hscode_recommend`(HS코드 추천)와
완전히 독립된 폴더입니다.

## ⚠️ 이 코드의 검증 상태 — 꼭 읽어주세요

UN Comtrade 공식 Python 패키지(`comtradeapicall`)의 소스코드를 직접 읽고
실제 요청 구조(엔드포인트, 파라미터명)까지 확인한 뒤 짰지만, **제 실행
환경에서는 UN Comtrade 서버 접속 자체가 막혀 있어서 실제 응답을 받아본
적은 없습니다.** 특히:
- 응답 데이터의 컬럼명(`primaryValue`, `reporterDesc` 등)은 UN Comtrade
  API v1 공식 문서 기준으로 가정한 것이지 직접 확인한 건 아닙니다
- `reporterCode`를 비워서 "전체 국가"를 한 번에 조회하는 게 실제로
  되는지도 검증 못 했습니다

**처음 실행했을 때 에러가 나거나 이상하면:**
```bash
python cli.py --hscode 190590 --country Vietnam --debug
```
이 명령이 UN Comtrade의 원본 응답 컬럼명을 그대로 출력해줍니다. 그 결과를
저에게 보여주시면 바로 정확하게 고쳐드릴게요.

## 매트릭스 비교 (여러 후보국 한 번에) — KOTRA TriBig "품목별 유망시장"에 대응

`/matrix` 화면은 국가 하나씩 따로 조사하는 대신, HS코드 하나로 여러 후보국을
한 페이지에서 비교합니다. KOTRA TriBig의 "품목별 유망시장" 화면 구성을 그대로
참고해서 아래 순서로 만들었습니다:

1. **세계시장 교역 현황** — 이 HS코드를 전세계에서 가장 많이 수입/수출하는
   나라 순위 (버튼으로 수입↔수출 전환, 서버 재호출 없이 즉시 전환됨)
2. **주요국 세계시장 점유율 추이** — 최근 5개년 동안 주요국(+한국 강제 포함)이
   "세계 시장 전체" 대비 몇 %를 차지했는지 라인차트로 추이 표시
3. **한국 수출입 신고 추이(관세청 기준)** — `customs_trade_stats.py`의 월별
   데이터를 연도 단위로 합산한 막대그래프. 일부 월 자료가 아직 없는 연도는
   `*` 표시로 "부분 집계일 수 있음"을 알려줍니다.
4. **유망시장 순위(버블차트)** — 아래 "버블차트 설계" 절 참고
5. **성장률 x 한국 점유율 매트릭스** — 기존 4분면 매트릭스(그대로 유지)
6. 후보국별 상세표, AI 전략 시사점

### 버블차트 설계 (유망시장 순위)

- **X축** = 수입금액이 큰 순서(순위). ⚠️ 트라이빅이 실제로 이 순위를 어떤
  공식으로 매기는지(단순 수입액순인지, 성장률/점유율을 섞은 자체 점수인지)는
  공개돼 있지 않아서 그대로 재현하지 않았습니다 — 저희는 정직하게 "수입금액이
  큰 순"으로만 계산합니다.
- **Y축** = 공급국 다양성(`supplier_country_count`): 그 나라가 이 품목을 몇
  개국에서 수입해오는지. `get_competitiveness()`가 이미 받아온 응답에서 그대로
  계산하므로 API를 추가로 부르지 않습니다.
- **버블 크기** = 수입금액. **반지름이 아니라 "넓이"가 값에 비례하도록
  제곱근(sqrt)으로 스케일링**합니다 — 반지름을 값에 그대로 비례시키면 원의
  넓이는 반지름의 제곱이라 큰 값이 실제보다 훨씬 커 보이는 착시가 생기기
  때문입니다.
  ```
  반지름 = 최소반지름 + (최대반지름 - 최소반지름) × sqrt(값 - 최소값) / sqrt(최대값 - 최소값)
  ```
  (`app.py`의 `_with_bubble_positions()` 참고. 수입금액이 4배 차이나면 반지름은
  약 2배 차이로만 그려집니다 - 이게 넓이 기준으로는 정확히 4배 차이입니다.)
- 버블을 **클릭**하면 회색 상세정보 박스가 뜹니다(순위/수입금액/한국 수출금액/
  공급국 수 + "이 국가 상세보기" 링크로 단일국가 화면 이동). 순수 바닐라 JS로
  구현했고 차트 라이브러리는 안 씁니다.

기존 "성장률 x 한국 점유율" 매트릭스는 다른 질문("우리가 어디를 공략해야
하나")에 답하고, 이 버블차트는 다른 질문("전세계 어느 시장이 크고 경쟁이
얼마나 분산돼 있나")에 답하므로 둘 다 남겨뒀습니다.

```
                한국 점유율 높음
                       │
  현상유지/수확        │   집중 공략        ← 가장 우선순위 높음
  ─────────────────────┼─────────────────── → 그 나라 수입 성장률
  우선순위 낮음        │   경쟁력 강화 필요
                       │
                한국 점유율 낮음
```

- **집중 공략**: 시장도 크고 있고 한국도 이미 선전 중 → 투자를 늘릴 만한 시장
- **경쟁력 강화 필요**: 시장은 크는데 한국은 아직 자리를 못 잡음 → 기회는 있으나 차별화/마케팅 필요
- **현상 유지/수확**: 한국 점유율은 높지만 시장 성장은 둔화 → 새 투자보다 기존 관계 관리
- **우선순위 낮음**: 성장도 점유율도 낮음

기준선(점선)은 비교한 후보국들의 **평균값**입니다. 국가 1개만으로는 매트릭스가
의미가 없으니 후보국은 2개 이상 넣어야 합니다.

**웹 화면**: http://127.0.0.1:5070/matrix 접속 (메인 화면에서도 링크로 이동 가능)

**터미널**:
```bash
python cli.py --hscode 190590 --matrix                        # 글로벌 수입 상위 10개국 자동 비교
python cli.py --hscode 190590 --matrix --candidates VNM THA PHL # 후보국 직접 지정
```

후보국을 직접 지정하지 않으면 이 HS코드를 가장 많이 수입하는 상위 10개국을
자동으로 후보로 삼습니다(웹 화면에서는 "자동 후보 개수"로 몇 개국까지
자동으로 가져올지 조절 가능). 데이터가 부족해 성장률이나 한국 점유율을
계산할 수 없는 후보국은 매트릭스에서 빠지고 "제외된 후보" 목록에 따로
표시됩니다.

## 관세청 공식 자료 교차검증 (선택 기능)

UN Comtrade는 "상대국이 한국으로부터 수입했다고 UN에 보고한" 미러 통계입니다.
반면 한국 관세청은 "한국이 직접 신고한" 수출입 통계를 갖고 있는데, 운송비·
보험료 포함 여부나 집계 시점 차이 때문에 이 둘이 다른 숫자를 낼 수 있습니다.
이 기능을 켜면 단일국가 화면(`/`)의 ④번 섹션에 관세청 수치를 UN Comtrade
수치와 나란히(라벨을 분리해서) 보여줍니다.

**완전히 선택 기능입니다.** 키를 안 넣으면 이 섹션만 "설정 안 됨" 안내가 뜨고
나머지 UN Comtrade 기능은 그대로 동작합니다.

### 준비물

1. https://www.data.go.kr 에서 아래 두 데이터셋을 각각 "활용신청"
   (보통 빠르게 자동 승인됩니다):
   - `관세청_품목별 수출입실적(GW)`
   - `관세청_품목별 국가별 수출입실적(GW)`
2. 승인 화면의 인증키를 `.env`의 `DATA_GO_KR_API_KEY`에 입력 (계정당 키 1개 공용)
3. 각 데이터셋 "활용신청 상세" 화면의 **요청 URL(Endpoint)**을 그대로 복사해서
   `.env`의 `CUSTOMS_ITEM_API_URL`, `CUSTOMS_ITEM_COUNTRY_API_URL`에 붙여넣기
   (이 URL은 데이터셋마다 달라서 기본값을 넣어두지 않았습니다)

### ⚠️ 이 부분도 검증 상태를 알려드립니다

`customs_trade_stats.py`는 data.go.kr에 등록된 API 대부분이 따르는 "공공데이터
개방 표준" 응답 형식을 가정하고 짰지, 이 두 API의 실제 응답을 받아본 적은
없습니다. 요청 파라미터명(`hsSgn`, `startYyyyMm` 등)과 응답 필드명
(`expDlrAmt`, `cntyKorNm` 등)이 추정입니다. 처음 실행해서 이상하면:

```bash
python customs_cli.py --hscode 190590 --debug
```

이 명령이 원본 응답과 실제 필드 목록을 그대로 출력합니다. 결과를 알려주시면
바로 고쳐드릴 수 있습니다.

정상 동작 확인은 이렇게:
```bash
python customs_cli.py --hscode 190590 --country 베트남 Vietnam
```

### 국가 매칭은 왜 별도 코드 변환이 필요 없나요

"품목별 국가별" API를 국가 필터 없이 부르면 전체 국가가 응답에 다 들어있다고
가정합니다. 그러면 이 응답 자체가 곧 "국가명 목록" 역할을 하므로, UN Comtrade
때처럼 ISO3 코드로 미리 변환하거나 AI에게 코드를 추천받을 필요가 없습니다 —
화면에 입력한 국가명(원문 그대로 + 우리가 아는 한글 별칭들)을 응답 속 국가명과
문자열로 대조하기만 하면 됩니다. 매칭에 실패하면(표기가 다르면) 조용히 넘어가지
않고 "매칭 실패" 안내를 화면에 그대로 보여줍니다.

## 국가 입력

한글/영문 이름(예: "베트남", "Vietnam`) 또는 ISO3 코드(예: `VNM`)를 받습니다.
`un_comtrade.py`의 `KOREAN_NAME_TO_ISO3`에 한국의 주요 교역국 위주로
등록되어 있고, 없는 나라는 ISO3 코드를 직접 입력하면 됩니다.

## 데이터 관련 주의사항 (UN Comtrade 자체의 특성)

- **보고 지연**: 많은 국가가 당해 연도 통계를 1~2년 늦게 제출합니다.
  최근 연도를 조회했는데 데이터가 없으면 `--years`로 더 이전 연도를
  지정해보세요.
- **CAGR 계산**: 단순 평균 증감률이 아니라 `(종료값/시작값)^(1/연수) - 1`
  복리 공식으로 계산합니다.
- **AI 해석은 참고용**: OpenAI에게 "제공된 수치만 쓰고 새로 지어내지
  말라"고 명시했지만, 실제 의사결정 전에는 원본 수치(①②③)를 직접
  확인하시길 권장합니다.
