# tavily_v4 — 박람회 준비 데스크 리서치

해외시장조사 담당자가 하는 방식을 그대로 옮긴 도구입니다.
제품과 국가를 입력하면 4가지 조사 질문에 대해 원문을 찾아 **문장 그대로 발췌**하고,
원문에서 확인된 문장만으로 AI가 요약합니다.

> 원칙: **AI는 사실을 쓰지 않는다. 원문에서 찾아 붙이고, 정리만 한다.**

## 설치와 실행

```bash
cd tavily_v4
python -m venv .venv
.venv\Scripts\activate            # Mac/Linux: source .venv/bin/activate
pip install -r requirements.txt

python app.py                     # 웹 화면: http://127.0.0.1:5050
python cli.py --product 김부각 --country Germany
python cli.py --product 김부각 --country Germany --exhibition ANUGA --website anuga.com --strengths "찹쌀 코팅 수작업"
python cli.py --product 김부각 --country Germany --audit 10   # 발췌 무작위 점검
```

`.env`는 저장소 최상위(`SABUZAK/.env`)를 자동으로 찾아 씁니다. 필요한 키는 `OPENAI_API_KEY`, `TAVILY_API_KEY`입니다.
실행하면 첫 줄에 사용 중인 `.env` 경로가 출력됩니다.

## 조사 방식

| 전문가가 하는 일 | 이 도구에서 |
|---|---|
| ① 조사 질문을 먼저 정한다 | 아래 4개 질문 고정 |
| ② 믿을 만한 곳에서 찾는다 | Tavily 검색. 제품명은 현지에서 실제 쓰는 용어로 바꾸고, 검색 결과에 등장하는 용어만 사용 |
| ③ 원문을 스크랩한다 | AI가 질문에 답하는 문장을 **원문 그대로** 발췌 → 코드가 원문과 글자 그대로 대조, 없으면 버림 |
| ④ 여러 곳에서 확인한다 | 같은 문장이 나온 출처 수 표시 |
| ⑤ 사실 → 의미 → 할 일로 정리한다 | 확인된 발췌만 근거로 요약. 발췌에 없는 숫자를 쓴 문장은 코드가 제거. 해석은 "AI 해석"으로 구분 |
| ⑥ 사람이 검토한다 | 모든 요약 옆에 발췌 원문·번역·날짜·링크 표시 |

### 조사 질문

| | 질문 |
|---|---|
| Q1 소비자 | 현지 소비자는 이 제품군을 언제, 왜 먹고, 무엇에 불만이 있는가 |
| Q2 경쟁 제품 | 현지에서 팔리는 경쟁 제품은 무엇이고, 얼마에, 어떤 메시지로 파는가 |
| Q3 바이어·유통 | 바이어·유통사는 무엇을 보고 제품을 들여오는가 |
| Q4 박람회·부스 | 이 박람회의 트렌드와 부스 운영·시식 사례는 무엇인가 |

마지막에 조사 결과와 우리 제품 정보(선택 입력)로 **부스 기획 포인트**(핵심 메시지, 근거, 아이디어)를 AI 제안으로 보여줍니다.
박람회 공식 사이트를 입력하면 Q4는 그 사이트 안에서도 검색합니다.

## 화면 읽는 법

| 표시 | 의미 |
|---|---|
| 원문 발췌 | 출처 원문에 글자 그대로 있는 문장 (코드 확인 완료) |
| AI 요약 | 발췌 내용만으로 AI가 쓴 결론·사실 정리. 번호를 누르면 근거 발췌로 이동 |
| AI 해석 / AI 제안 | 발췌를 바탕으로 한 AI의 판단. 출처로 확인된 내용이 아님 |
| 확인 필요 | 이번 조사로 답하지 못한 부분 |

## 보장하는 것과 보장하지 못하는 것

**보장**: 근거로 표시된 모든 발췌 문장은 출처 원문에 실제로 있습니다. 요약 문장의 숫자는 모두 근거 발췌에 있는 숫자입니다.

**보장 못 함**: AI가 발췌를 잘못 해석하거나, 번역을 부정확하게 하거나, 맥락을 놓칠 수 있습니다.
그래서 요약 옆에 항상 원문 발췌를 붙였습니다. 중요한 결정 전에는 발췌와 링크를 직접 확인하세요.
`--audit`으로 발췌를 무작위로 뽑아 번역·요약이 맞는지 주기적으로 점검할 수 있습니다.

## 알아둘 점

- 같은 보도자료를 여러 매체가 옮겨 쓰면 "같은 문장 출처 N곳"이 크게 나올 수 있습니다. 출처 수는 참고용입니다.
- 날짜는 검색 결과가 제공할 때만 표시되며, 없으면 "날짜 미상"입니다.
- 틈새 품목이나 비영어권 시장은 자료가 적어 "확인 필요"가 많이 나올 수 있습니다.
- 캐시: 검색 결과는 쿼리 단위, 조사 결과는 입력 단위로 30일 저장 (`research_cache.db`).
  검색 캐시에는 원문 일부가 저장되니 외부에 공유하지 마세요. 화면·리포트에는 발췌·링크·날짜만 남습니다.
- 비용(1회): Tavily 용어 확인 basic 최대 4회 + 검색 advanced 약 5~7회, OpenAI 용어 1회 + 발췌 3~4회 + 요약 4회 + 부스 1회.
  개발 중에는 `research.py`의 `SEARCH_DEPTH`를 `"basic"`으로 바꾸세요.
- 질문이나 프롬프트를 바꾸면 `research.py`의 `VERSION`을 올려 이전 결과 캐시를 무효화하세요.

## v3.2와 달라진 점

v3.2는 AI가 쓴 사실을 사후에 검사하는 규칙(고유명사 대조, 교차 확인 등급, 구체성 검사, 과거 수치 판정)이 많아 복잡했습니다.
v4는 AI가 처음부터 **원문 문장을 그대로 발췌**하게 하고, 코드는 "발췌가 원문에 있는가"와 "요약 속 숫자가 발췌에 있는가"
두 가지만 확인합니다. 코드가 짧아지고, 담당자는 발췌 원문을 직접 보며 판단할 수 있습니다.
